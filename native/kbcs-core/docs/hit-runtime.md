# 命中本体と所有状態（JP15.7.2）

対象は1507021 / arm64-v8a / SHA `6122e24879d58db6b0beceb43e2a6ee62d008a586fc03b7cb7726214bc86f3ea`。`006e4aec`（味方→敵）、`006e79bc`（敵→味方）を`actor_hit`へ移植した。既存の21段階数値APIはDB表示用に維持し、命中入口の代用にしない。

`actor_hit_source.py`が文字列構築・破棄とmap/vectorを置換し、ゲームの分岐・goto・整数化を保持する。`export_actor.py`がgetter/setterも含めて生成する。`006e4b48`の呼出先は`00a94678→00a94484`で、W2は攻撃元slotを保持する。Ghidraが落とした第3引数を戻す。`006e60f0`の赤対象getterにも攻撃元slotを渡す。敵の赤属性呼出に復元された余分な引数は実命令のW1に合わせる。

## 入力と関係

- `SecondaryHit.attack_type`はparam2（直接0/波動1/烈波2/爆波3）、`DirectHit.kind`はparam6（通常0/小波動1/小烈波2）。混同しない。
- `HitContext`は味方の形態・無本能の段別攻撃、属性付きの玉5種×引数2、通常の玉32種、果実32種、param.tsvの5値、土台12属性と装飾3種を持つ。属性付き玉は**今回命中する相手の属性map**から解決する。すべての相手へ同じ玉倍率を流用しない。
- `Clock`は撃破強化の玉の有効条件と閾値。`DamageContext`は城無敵の出現表・状態と通知。`EffectContext`の4値は妨害用の装飾軽減で、12属性の土台軽減と別。
- param.tsvの5値は順に`battle_wave_s_st`、`battle_super_beast_hunter`、`battle_super_sage_hunter_damage1`、`battle_super_beast_hunter_df`、`battle_super_sage_hunter_damage2`。コードの既定値1600/700等を現版ファイルの値に代用しない。
- `006e60f0`をそのまま使い、果実の最大値と同率時の後勝ち順を残す。`00a5b084`の比較用取得値と`00a5b1b4`の効果取得値を別入力にする。

命中はHPを直接減らさず、回避、効果付与、ダメージ予約を行う。後で保護→HP→集計→反応を原本順に実行する。`actor_hit`成功でも0ダメージがあり、回避/入口拒否のapplied=falseと区別する。敵の毒撃は別計算を加算し、最後の波動等無効で通常分と一緒に0へ戻す。超獣の特殊回避成功と通常の無敵回避も別の分岐。

`Hits`は敵slot別のメタルキラー率の列と、敵生成通番別の攻撃者通番の列を所有する。前者は同じ率も繰返し追加し、後者は原本のwmemchrと同じく初回だけ追加する。率の列は保護判定より前に現在HP基準で順に予約し、フレーム末尾で消す。寄与者列は死亡・報酬確定後にキーを消す。slotの再利用を生成通番の代用にしない。

Rust `Hits`は生成/Drop、apply、values、eraseを持つ。apply中だけ個体・行状態を借用し、外部ポインタを保持しない。内部失敗したHitsは後のapplyを拒否する。失敗で部分更新された戦闘を継続しない。

## 照合
