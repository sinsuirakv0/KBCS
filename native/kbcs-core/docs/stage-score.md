# スコア報酬と重み報酬の確定（0.1.12）

2026-10-23、JP15.7.2 ARM64 / ruleset1507021。版・SO SHAは[番台調査](../../../research/docs/stages/README.md)と共通。0.1.11の選択に続き、005d996cのスコア報酬と重み選択後の履歴処理を局所実行した。計算・付与要求と、実所持数への付与は分ける。

## 追加セル群はスコア報酬

MapStageDataの0基準15列が1のときに、16列以降の「閾値・報酬ID・数量」3列組を使う。この旗を確認する必要があり、mode−2だけから有効と推定しない。旗は309面にあるが、通常モードではヘッダー列2のスコア保存番号0..199も必要。有効は301面（すべてmode−2）。保存番号なしの8面（mode−3が7、−4が1）は処理を通らない。数値0の閾値・空欄・重複と原本の並びを保持する。閾値列の−1が終端で、原本の最大10組まで扱う。

`score::calculate`→`kbcs_core_stage_score`は、解決済みの計測カウンター、前回最高、閾値を受け取り、今回スコア・更新後最高・更新フラグ・新規報酬ビット集合を返す。Inputはelapsed/best/count/thresholds[10]、Outputはscore/best/improved/reward_mask。ABI2へ別PODと入口を追加し、既存の型を変更しない。

elapsedは原本game+0x83e74の非負整数で、画面の秒数をそのまま渡す契約ではない。加算元は006d6d04の受理更新で、phase0なら1増加し30000で飽和する。score::advanceで24境界を照合。外側の速度・一時停止と時間表示への換算は未検証。

|条件|スコア|
|---|---|
|elapsed<=9000|10000−elapsed|
|9000<elapsed<19000|1000−floor((elapsed−9000)/10)|
|19000<=elapsed|0|

9000〜9009で1000、9010で999、18999で1、19000で0になる。計算後、前回最高を上回った場合に限り`oldBest < threshold <= score`の各枠を要求する。ビットiは原本i番目で、実付与のID列は17+3i、付与関数第3引数は1。全件をソートしたり、複数の閾値を越えたとき最後の1件だけへまとめたりしない。

元のスコア処理は各要求の付与を順に試み、その後で最高記録を保存する。付与関数006e34b0の戻り値が1なら、その要求の結果行は作らない。一方、最高記録と更新フラグは進む。カーネルのreward_maskは要求された枠であり、実際に表示した結果行や増えた所持数とは別。ホストはoldBestを保持して要求を処理し、最後にbest/improvedを保存する。

入力はelapsed>=0、best/閾値0..10000、count1..10。検査完了後に出力を代入し、エラー1で途中を書き換えない。保存先が未解決、スコア旗なし、初期化前の負記録をこの入口へ黙って流さない。

## 重み選択後の履歴

`reward::weight_finish`→`kbcs_core_reward_weight_finish`は選択に成功したmode−3/−4、解決済みのmap×stage履歴seen、レーダー、正規化候補番号0..9を受け取る。出力はgrant_column（なし−1）、mark_history、radar_blocked。所持数や保存領域をこの関数は所有しない。

|条件|付与要求|履歴|レーダーによる打切り|
|---|---|---|---|
|mode−3・未記録|あり|付与前に記録1へ|なし|
|mode−3・記録済み|なし|維持|レーダーありなら1|
|mode−4|あり|維持|なし|

grant_columnは候補0で6、それ以外で3×候補番号+7。これは原本の報酬ID列であり、キャラのIDでも結果行の番号でもない。付与関数の第3引数は0。mode−3の履歴は冠別の通常ドロップ取得済みバイトとも、特殊報酬の所持判定とも別。

履歴の記録は付与より前。付与結果1でも履歴を戻さず、重み報酬の結果行は作る。スコア報酬の結果行除外とは異なる。所有ランタイムはmark_historyを先に保存→付与→結果行の順に処理する。同じ未記録入力を再利用して二重付与しないよう、候補と更新を一度だけ確定する責任も所有側にある。

今回のnative試験は既存のmap/stage treeノードを用意し、00a09734の実getterも確認した。新規ノード挿入・木の平衡化・セーブ永続化まで移植/検証したものではない。保存形式の実装を計算カーネルへ複製しない。
