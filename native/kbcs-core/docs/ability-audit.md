# 特性の監査と計算範囲

2026-10-21、JP15.7.2。内蔵DBのキャラ特性54種と敵特性37種、通常・超本能、コンボを照合した。データに存在すること、整数計算があること、戦闘状態を再現することを区別する。

|区分|対象|現在の扱い|
|---|---|---|
|基礎値|成長・章別お宝・HP/攻撃コンボ・通常本能・超本能|詳細表と成長グラフをC++へ接続|
|通常の特効・軽減|めっぽう強い、超/極ダメージ、打たれ/超打たれ強い|各段をC++で整数化。複合属性でも同じ特性は一回。果実は属性別設定から最大を選ぶ|
|特殊種別|魔女、使徒、超生命体、超獣、超賢者|両方向を実命令と照合。発動・種別一致を入力してC++へ渡す|
|怪人特効|にゃんコンボtype25（例：レッドパワー）|見落としを修正し、編成・C++の両方向へ接続|
|命中の補正|クリティカル、渾身、体力低下時強化、弱体化、城破壊、ターゲット限定、呪い/呪い無効|C++の整数経路へ条件を渡す。発動抽選・状態の経過Fはまだランタイム未実装|
|メタル|非クリティカルの1化、味方メタルボディ|通常攻撃の最後の段としてC++で処理|
|メタルキラー|味方CSV112|通常攻撃と別の現在HP割合入口。予約順の基準HP更新を検証。画面は有効な1撃を表示|
|毒撃|敵のtoxic、味方の毒撃耐性/無効|敵側専用の最大HP割合入口。属性軽減・土台・メタルを適用しない|
|土台・装飾|土台7種、装飾7種、Lv0〜20|原本と現版ネイティブの補間を照合。ダメージ条件へ接続。妨害時間の装飾は時計側が未実装|
|攻撃の耐性・無効|波動/烈波/爆波耐性・無効、波動ストッパー|被ダメージの数値は反映。波動そのものの遮断・他部隊保護は発生/伝播処理待ち|
|本能玉|加算攻撃、軽減、強い/超ダメ/打たれ強い強化、撃破後強化|C++はネイティブ集計値の入力に対応。装着UI・枠解放・発動状態の管理は未実装|
|攻撃の形状|連続攻撃、遠方、全方位|段ごとのダメージを計算。距離・対象捕捉・城射程・空振りは戦闘側が未実装|
|追加攻撃|波動/小波動、烈波/小烈波、爆波、烈波反射、敵の死亡時烈波|直接攻撃やDPSへ勝手に加算しない。効果の発生・寿命・範囲・再命中が未実装|
|保護・生存|バリア/シールドと両ブレイカー、攻撃無効、回避、生き残る、蘇生|単純なHP倍率にしない。判定順・残量・状態の実装が必要|
|妨害|止める、遅くする、弱体化、ふっとばす、呪い、ワープ、再生産遅延と耐性/無効、衝撃波無効|保存・表示あり。妨害の発動、持続F、移動・生産への接続は未実装|
|退場・召喚|お金2倍、ゾンビキラー、魂攻撃、精霊、自爆、敵の潜行/蘇生|通常ダメージの倍率にしない。報酬・対象・出現/退場状態は未実装|
|生産回数|2回生産ごとの再生産短縮|本能72に加えてCSV118の素の能力を追加。いなばの白うさぎ50%、メガシャークVS白うさぎ75%。表示と保存を修正、偶数生産の時計はランタイム待ち|

CSV118は現在のデータで非0が2形態。`00aa5f84`が列118と本能72を加算し、`009f1e64`が出現側へ渡し、`00aa6010`が有効条件を調べる。原本を再生成するためIMPORTER_VERSION=6へ更新した。テーブル構造は変わらずSCHEMA_VERSION=5。以前のsnapshotは保持する。

`damage-calculator.js`の「相手の属性を適用」は属性/特殊種別を選ぶ操作。実敵のHP・倍率・攻撃列・バリア等を自動で再現する戦闘開始操作ではない。被ダメージの一撃は明示入力。敵専用の毒撃を味方攻撃へ混ぜない。

将来のシミュレーターは同じC++入口を呼び、上記の未実装状態を前後に接続する。現在の表示用コードを戦闘全体の確定仕様として流用しない。
