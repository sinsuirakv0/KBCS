## 所有と呼出関係

- `interface.cpp` は借用PODの純粋計算。キャラのLv・本能・玉・DB・描画先を所有しない。成功時だけ出力を確定する。
- Rust `interface` → Serviceの `combo-layout` / `combo-plan` / `battle-info` が共通入口。既存ABI5へ追加した独立関数で、旧関数名を別の意味に置換しない。

- 乗算帯は背景・個体と同じGPU描画先へ転送し、HUDの不透明部分にも同じRGBを乗算する。透明HUDへ単純な塗りを重ねて背景を隠さない。
