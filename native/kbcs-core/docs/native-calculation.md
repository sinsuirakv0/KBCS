## 確認した順序

体力と各段の攻撃力は、`(base×growth+50)/100`→`grown+grown×treasure/100`→コンボ→通常本能→超本能。各段で整数化。10/11、20/21、199/200Lvを、区間ごとに違う成長率でも確認した。章の完成率45%ずつは、最大加算50を各章で整数化して22+22+22=66となる。

直接攻撃はクリティカル→体力低下による強化→味方の撃破後強化玉→弱体化→渾身→属性特性→魔女→使徒→超生命体→超獣→超賢者→怪人特効。味方側はその後に原本一撃を使う玉の加算とメタル判定。敵側は攻撃耐性→軽減玉→対象属性の土台→攻撃種別の装飾→メタル判定。無効処理は別のゲートとして扱う。これは命中計算の局所経路で、戦闘全体のイベント順の確定ではない。

強い・超ダメージ・極ダメージの分数はそれぞれ `(1500+fruit+orb)/1000`、`(900+fruit+orb)/300`、`(1500+fruit)/300`。対応するコンボはその後に整数化する。防御側は `(1500-fruit)/3000`、`(1500-fruit)/6000`、`(2100-fruit)/12600`を使い、コンボ・玉を別段階にする。

魔女の軽減は先に`damage/10`、使徒は`damage/5`を整数化し、コンボ補正を次に掛ける。単一の小数倍率へまとめない。原本の超獣は2500/1000・600/1000、超賢者は1200/1000・500/1000。コード内の既定1600・700等は採用しない。怪人特効はコンボtype25の2500/1000、受ける側は逆数を使う。

毒撃は味方最大HPの割合を最低1へ整数化し、毒撃耐性で再度整数化・最低1、最後に専用装飾。HP101/20%/耐性50/装飾3333なら6。毒撃無効は0。土台・属性軽減・メタルの1化を通らない。

メタルキラーはparam.tsvの`battle_metal_killer_hp_type=1`により現在HPを選ぶ。各予約割合を最低1で計算し、割合用の基準HPを減らして次へ進む。HP101に20%が同Fで2件なら20+16。通常攻撃の保留分を先に基準HPから引かない。HP0へ達した後も同じ予約列には最低1の加算が残る。別Fの対象生存・削除判定はランタイムの責務。
