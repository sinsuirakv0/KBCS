# KBCS 0.1.38

Macの空き容量取得で発生した整数型の不一致を修正しました。

テスト・ビルド・単独起動検査に成功した環境から順に公開します。下の **Assets** から使用する端末のZIPを取得してください。

| 端末 | ファイル名の末尾 |
| --- | --- |
| Windows | `windows-x64.zip` |
| Mac・Mシリーズ | `macos-arm64.zip` |
| Mac・Intel | `macos-x64.zip` |

未掲載の環境はビルド中または失敗しています。前のリリースの対応ZIPを利用してください。Windowsのみ成功した場合も更新できます。Macは対応版が追加されるまで、最後に成功した版を案内します。

[インストール手順](https://github.com/sinsuirakv0/KBCS/blob/kbcs-v0.1.38/README.md)

C++の並列コンパイル、途中失敗時のキャッシュ保存、共通チェックの集約を追加しました。配布版の計算式・最適化設定は維持しています。

ZIPのSHA-256とビルド情報JSONを添付し、全ソースはSource codeから取得できます。配布済みZIPは上書きしません。

[前回からの変更](https://github.com/sinsuirakv0/KBCS/compare/kbcs-v0.1.37...kbcs-v0.1.38)
