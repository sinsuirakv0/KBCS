# KBCS 0.1.36

Windows・Apple Silicon Mac・Intel Mac用のアプリです。ソースコードからGitHub Actionsでビルドしています。

## ダウンロード

- **Windows**: `KBCS-0.1.36-windows-x64.zip`
- **Mac・Mシリーズ**: `KBCS-0.1.36-macos-arm64.zip`
- **Mac・Intel**: `KBCS-0.1.36-macos-x64.zip`

[インストール手順](https://github.com/sinsuirakv0/KBCS/blob/kbcs-v0.1.36/README.md)を参照してください。初回起動時はゲームデータをダウンロードします。Mac版はmacOS 14以降が対象で、開発用署名のため初回にOSの起動確認が必要になる場合があります。

## 変更

- WindowsとMacで同じUI・C++戦闘カーネルを使用。MacはApple Silicon/Intel別に生成。
- 統合データの全ZIPを取得・検証し、アプリのデータ領域へ保存。導入済みの版との比較、初回自動取得、後からの手動更新に対応。
- 本体更新をOS・CPU別の配布ZIPへ接続。Macは署名とSHAを検証してアプリを置き換える。
- 編成の一時5枠、出撃準備の操作、BGMシーク、戦闘のチート設定・最大20倍再生・表示比率等の更新を含む。
- push時にWindows/Mac両CPUの計算テスト・ビルド・ZIP作成を自動実行。`kbcs-v<版>`タグでは、3種類の成果物が揃った後にこのリリース形式で公開。

開発途中のシミュレーターです。今回のCPU別計算テストは、全ゲーム挙動やMac実機での画面表示が検証済みという意味ではありません。

ZIPごとのSHA-256とビルド情報JSONも添付しています。コンパイル前の全ソースは、このページのSource codeから取得できます。
