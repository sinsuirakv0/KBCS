# ステージ詳細とC++描画（0.1.21）

既存C++の報酬抽選をDB詳細へ接続する。reward::policyは取得前後×レーダー有無を条件入力として既存stage_pick/weight_finishを呼び、取得記録の単位と判定を返す。通常報酬mode2のみ冠別スロット、mode1は共有。特殊報酬クラスは所有判定、mode-3は履歴を使う。実際のユーザー取得状態は保存しない。

画面は元列8の抽選モードをrandとして表示する。末尾rewardOnceと同一視しない。条件プローブは最初の比較成立を仮定した結果で、実ステージの確率や所持状況を返すものではない。根拠は既存event-rewards.mdとJP15.7.2 ARM64の005d996c/00a092a0/00a0956c。

背景・城・BGMを詳細上部へ追加。背景拡大はC++から描画命令を受け、パン・拡大・両城切替・演出再生・画像保存が可能。背景演出は独立時計で、戦闘結果へ影響しない。詳細な入口・検証限界はnative/kbcs-core/docs/render.md。

データはスキーマ8を維持し変換器13へ更新。旧snapshotを変更せず、背景CSV/JSON、画像、分割、モデル、アニメーション、城CSVをsource_fileへ追加する。一度の再取り込み後はアプリ更新だけで再解析しない。

回帰資料の生成は `node research/verify/render_pose_reference.mjs ASSETS` と `node research/verify/render_effect_reference.mjs ASSETS LAB`。参照リポジトリは読み取り専用。生成は元評価器の回帰基準を更新するため、C++結果で期待値を上書きしない。

単体の味方・敵・その他モーションも/api/motion-poseへ接続。16F単位の先読みで同じC++姿勢を取得し、表示マスクやGPU転送をUIへ残す。描画用のJS評価は呼ばず、旧評価器はパーツの解析表示と回帰基準に限定する。未検証のフレーム補間は無効化する。
