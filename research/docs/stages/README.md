## 関数の関係と番台以外の分岐

- `007cf4b0`：章・ゾンビ・襲来・選択モードなどの状態から現在の内部種別を決める。
- `009a3a30`：種別・フラグに応じたMapStageData / stageNormal等を選び、ステージ一覧情報を読む。
- `0099fe4c`：一覧用の補助読込と戦闘用読込を引数で分け、stageRN / stageZ / stageSpace等を選ぶ。Lは`0071b5b4`経由で選択したテンプレート番号を使う。
- `00a06ae4`：敵出現の数値セルを14個の整数へ読み、列2・3・4を×2。`00a06c30`の列0非0判定で終端を決める。
- `007cebc8`：マップID別・冠別倍率を取得する。データ欠落時の既定値は100＋冠番号×50。
- `006ef2b0`：城条件・出現数・待機・撃破条件・全体の生産待ちを処理し、出現可能な行を後ろから選ぶ。行の時刻だけを並べた一覧は実際の出現スケジュールではない。

この段階ではEXの連戦・抽選、クエストの参照元、迷宮の階層とテンプレート、ゾンビ/襲来の状態、特殊ルールを共通化しない。それぞれの番台で、呼出元・追加ファイル・同一ID内のvariantを調べる。

当時の記録：`crates/kbcs-data/src/progression.rs`の入手先用GROUPSにはPR=32が残っていた。現行はPR=39へ修正済み（da4fff44に収録）。以下は修正前の調査経緯として保持する。一方、現版`007cd120(-26, 0)`は39000、`007cd2ac(32000)`は−1。原本Map_optionとMap_Nameにも39000が存在する。labの現在のcatalog.mjsはPR=39。この不一致は確定したが、旧snapshot・変換器へは今回書き込んでいない。ステージ用のID契約を共通化する際に修正し、IMPORTER_VERSION更新と旧入手経路の回帰照合をセットにする。

```powershell
python research/verify/stages.py --assets D:/KBC/KBC-rakv0-assets --python-libs D:/KBC/KBC-rakv0-lab/unit-db/research/python-libs
```
