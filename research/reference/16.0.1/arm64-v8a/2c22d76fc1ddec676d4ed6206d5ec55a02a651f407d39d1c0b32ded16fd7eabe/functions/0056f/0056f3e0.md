## 読み取り専用データ

- 参照命令 [`0056f3e8`](#insn-0056f3e8)

~~~json
{
  "source": "0056f3e8",
  "target": "0056f534",
  "target_space": "ram",
  "resolution": "boundary_unknown"
}
~~~
- 参照命令 [`0056f530`](#insn-0056f530)

~~~json
{
  "source": "0056f530",
  "target": "0056f400",
  "target_space": "ram",
  "resolution": "boundary_unknown"
}
~~~
